Sandbox

Python und SQL direkt im Browser ausprobieren. Echtes Python und eine echte SQLite Datenbank, ohne Installation und ohne Anmeldung.

Python wird geladen …

Strg oder Cmd + Enter führt aus. Mit Esc und danach Tab verlässt du den Editor per Tastatur.

Dein Browser erlaubt hier keine Live Eingabe. Trage die Antworten für input() vorab ein.

Ausgabe

Die Standardbibliothek ist dabei. numpy, pandas und weitere Pakete von Pyodide werden bei import automatisch nachgeladen. Diagramme (matplotlib) werden hier nicht angezeigt.

SQLite wird geladen …

Strg oder Cmd + Enter führt aus. Ist Text markiert, läuft nur die Markierung. Mehrere Befehle mit Semikolon trennen.

Ergebnis

Noch nichts ausgeführt.

Datenbank

Die Datenbank liegt nur im Arbeitsspeicher. Beim Neuladen der Seite ist sie weg, ausser du speicherst sie.
